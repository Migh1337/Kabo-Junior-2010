# Tachnoball

نظام حجز تدريبات قطاع الناشئين والبراعم.

## المحتوى الحالي
`prototype/index.html`: تصميم مبدئي تفاعلي (ملف واحد، يعمل على الموبايل) يضم:
- استمارة ولي الأمر وحجز الموعد مع كود حجز.
- لوحة الإدارة: المتقدمون، البحث والتصفية، سعة الأيام.
- كشف الجهاز الفني: الحضور والقرار (اجتاز / إعادة / لم يجتز).

المواعيد والأسماء تجريبية، والبيانات لا تُحفظ خارج الصفحة.

## الميزات
تذكير واتساب، تذكرة حجز بـ QR وتسجيل حضور بالكود، تصدير Excel، منع تكرار اللاعب، ملف لاعب كامل مع سجل الطول والوزن، مجموعات، سجل إصابات وجاهزية، مكتبة فيديو للمحلل، معرض صور بموافقة ولي الأمر، وإعلانات.

نقطة رجوع للنسخة القديمة: الوسم والفرع `backup/stable-before-ideas` (الإيداع 84a8811).

## المراحل التالية
قاعدة بيانات وتسجيل دخول للإدارة والمدربين، رفع المستندات، تصدير Excel/PDF، وحماية بيانات الأطفال.

## بناء ملف APK
تشغيل Build APK من تبويب Actions في GitHub، ثم تنزيل `tachnoball-apk` من نتيجة التشغيل. الملف نسخة debug قابلة للتثبيت على أندرويد.
