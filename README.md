# Tachnoball

نظام حجز اختبارات قطاع الناشئين والبراعم – نادي كابو (شركة النصر للملابس والمنسوجات).

## المحتوى الحالي
`prototype/index.html`: تصميم مبدئي تفاعلي (ملف واحد، يعمل على الموبايل) يضم:
- استمارة ولي الأمر وحجز الموعد مع كود حجز.
- لوحة الإدارة: المتقدمون، البحث والتصفية، سعة الأيام.
- كشف الجهاز الفني: الحضور، التقييم، القرار (اجتاز / إعادة / لم يجتز).

المواعيد والأسماء تجريبية، والبيانات لا تُحفظ خارج الصفحة.

## المراحل التالية
قاعدة بيانات وتسجيل دخول للإدارة والمدربين، رفع المستندات، تصدير Excel/PDF، وحماية بيانات الأطفال.
